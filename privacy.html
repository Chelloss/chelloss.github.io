Privacy Policy

Oldest Surviving Uploader · last updated 29 October 2026 (topic research added)

Oldest Surviving Uploader ("the tool") is a private tool run by the owner of the YouTube channel Oldest Surviving (@oldestsurviving), only for that channel. It has one user, the channel owner. It is not offered to the public.

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

What the tool accesses

  • Google sign-in tokens (OAuth access and refresh tokens) for the channel owner's own Google account.
  • Upload access (scope youtube.upload): to upload the channel's own videos and set their thumbnails. The tool sends the video file, title, description, tags, privacy status, scheduled publish time and the "made for kids", "altered or synthetic content" and "paid promotion" settings, and receives the new video's ID and status.
  • Later, read-only analytics (scope yt-analytics.readonly, with a separate sign-in): the channel's own statistics such as views, watch time, retention, traffic sources and aggregated audience figures.
  • Public search data for topic research (API key, no sign-in; search.list and videos.list, about 30 searches a week): the titles and public view counts of videos that answer a history question, used only to judge whether a topic interests viewers. No personal data. Kept at most 30 days, then deleted automatically.

What the tool does not collect

No personal data of viewers or other people, no viewer identities, no cookies, no tracking and no ads. This website sets no cookies and runs no analytics. Nothing is sold, shared or transferred to anyone.

How Google user data is used

Data from Google APIs is used only to publish and review the owner's own channel. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It is never used for advertising and never used to train AI models.

Storage and retention

  • The refresh token is kept in a protected file on a private machine controlled by the owner (the owner's computer for now, a private server later), readable only by the tool. It is never stored in code or shared.
  • An upload receipt (video ID and the settings sent) is kept for each of the channel's own videos, as part of the channel's production log.
  • Cached YouTube API data, and any data about other channels used for topic research, is deleted or refreshed within 30 days by an automatic daily cleanup job.

Revoking access and deletion

Access can be revoked at any time in Google's security settings at myaccount.google.com/permissions (also reachable at security.google.com/settings/security/permissions). Once access is revoked, or on request, the stored tokens and all stored YouTube API data are deleted within 7 days. The tool's own "revoke" command revokes the token with Google and deletes them at once.
